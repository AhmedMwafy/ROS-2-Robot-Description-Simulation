# ROS-2-Robot-Description-Simulation

This repository documents my learning journey through the **ROS 2 for Beginners Level 2: TF, URDF, RViz, Gazebo** course.

The goal is to understand how robots are described, visualized, and simulated using ROS 2, with hands-on practice and projects as I progress.

## Topics Covered
- TF (Transforms) and coordinate frames
- URDF: robot links, joints, and physical properties
- Xacro: reusable and cleaner robot descriptions
- `robot_state_publisher` and `joint_state_publisher`
- RViz visualization and configuration
- ROS 2 XML and Python launch files
- Gazebo robot simulation and custom worlds
- Simulated sensors and robot control
- Mobile robot and robotic arm projects
